# Examples

Copy-paste recipes that use the published `violet-ui` API. For a runnable app see `apps/playground` (`bun run dev`).

| Example                                                                  | Shows                                     |
| ------------------------------------------------------------------------ | ----------------------------------------- |
| [`login-form/LoginForm.vue`](./login-form/LoginForm.vue)                 | `useForm` + `VInput` + server-side errors |
| [`custom-field/ColorField.vue`](./custom-field/ColorField.vue)           | Building a custom input with `useField`   |
| [`theme-switcher/ThemeSwitcher.vue`](./theme-switcher/ThemeSwitcher.vue) | `useTheme` with light / dark / system     |
| [`custom-theme/main.ts`](./custom-theme/main.ts)                         | Brand themes with `createTheme`           |
| [`nuxt/violet-ui.plugin.ts`](./nuxt/violet-ui.plugin.ts)                 | Nuxt 3 integration with SSR theme styles  |
